# 水滴鱼 VI 与界面设计规格

## 文档状态

- 本文定义设置窗、鱼鱼聊天窗与角色系统台词的**目标规格**，供 SwiftUI / AppKit 实现与测试使用。
- 本文基于现有代码、语言包和角色 SVG 的结构整理；所列新布局与交互**尚未经过应用内人工视觉 QA**。
- 安全原则：设置界面不得显示、复制或记录设备私钥原文。

## 1. 设置窗目标规格

### 1.1 窗口骨架

| 项目 | 规格 |
| --- | --- |
| 默认内容尺寸 | `820 × 600 pt` |
| 最小内容尺寸 | `760 × 540 pt` |
| 侧栏 | 固定 `176 pt` |
| 分隔线 | `1 pt` |
| 底部操作栏 | 固定高 `54 pt` |
| 页面内容 | 独立滚动；侧栏和底栏不滚动 |

通用布局：

- 页面外边距 `20 pt`，卡片间距 `12 pt`。
- 卡片内边距 `14 pt`、圆角 `12 pt`。
- 表单行间距 `10 pt`；普通控件高 `30–32 pt`。
- 页面标题 22 pt Semibold，卡片标题 14 pt Semibold，字段 12–13 pt，辅助文字 11 pt。
- 页面底栏左侧显示保存或错误状态，右侧依次为`恢复默认…`和主按钮`应用`。
- 切换页面不自动保存；高级选项以 disclosure 收起。

### 1.2 侧栏

顶部品牌区高约 `58 pt`，只保留角色名与一行副标题。导航行高 `38 pt`、间距 `4 pt`：

1. 常规
2. 形象与表现
3. 时钟
4. 鱼鱼传话
5. 关于

侧栏底部只显示当前版本号。导航项不得附加任务状态或长说明。

### 1.3 页面信息层级

#### 常规

1. 界面语言与开机启动
2. 问候、作息与安静时段
3. Codex、Claude Code 与日历连接
4. 隐私与任务提示音

连接诊断默认折叠，只显示开关、简短状态和`管理连接`。

#### 形象与表现

1. 角色与实时预览
2. 大小、速度与水平／垂直游动
3. 有任务／无任务时是否游动
4. 表情与饰品
5. 性能面板

性能面板至少提供`左／右`、`与角色距离`和`垂直位置`三个维度。

#### 时钟

1. 当前计时器
2. 快速计时
3. 新建闹钟
4. 已保存闹钟
5. 响铃设置

快速计时说明固定为：`剩余 15 分钟时，角色会拿起小闹钟。`

#### 关于

1. 当前版本与更新状态
2. `检查更新`
3. 项目与隐私说明
4. 开源与第三方授权
5. 折叠的诊断信息

分支名、Electron 基线等开发信息只能放在诊断信息中。

### 1.4 鱼鱼传话页

#### 鱼鱼身份

状态必须同时显示图标和文字：

- `身份有效`
- `尚未建立身份`
- `身份无效`
- `正在检测…`

字段顺序：

1. `传话名称`
2. `中转地址`
3. `设置密钥（仅建立身份时使用）`

中转地址右侧提供`检测连接`，结果在字段下方内联显示：

- `中转服务可用`
- `无法连接中转服务`
- `地址必须使用 HTTPS`

设置密钥使用安全输入框，并说明：`只用于建立收件箱，不会保存到本机。`提交后立即清空，不进入日志。

无身份时显示主按钮`创建鱼鱼身份`。已有身份时显示`重新检测身份`和折叠项`身份维护`；破坏性操作只在展开后显示为`重建身份…`。

重建确认文案：

> 重建后，旧鱼鱼码将失效，现有好友需要重新配对。聊天记录不会自动迁移。

确认按钮为`仍要重建`。

身份有效性检测至少包括：

- Keychain 项目存在。
- 私钥格式有效且可推导公开密钥。
- 本地加密／解密自检通过。
- 中转地址是有效 HTTPS。
- 当前身份与生成的鱼鱼码一致。

界面只能显示：`私钥已安全保存在 macOS 钥匙串中。`不得把私钥原文放入 View state、剪贴板、日志或错误信息。

#### 我的鱼鱼码

- 仅在身份有效时启用。
- 默认显示首尾片段，例如 `fish1_abcd…wxyz`。
- 完整代码区最多三行，使用等宽字体并默认隐藏。
- 操作按钮为`显示完整代码`和`复制鱼鱼码`。
- 复制成功状态为：`已复制。只发给你信任的人。`
- 固定说明：`鱼鱼码包含向你投递消息的权限，不要公开发布。`

#### 添加好友鱼鱼码

- 多行输入框高 `68–76 pt`，右上提供`粘贴`。
- 主按钮为`验证并添加`。
- 验证必须覆盖前缀、Base64URL、协议版本、HTTPS、公开密钥长度、同一中转站、自身码和重复好友。
- 结果在字段下内联显示，不使用系统弹窗。

标准结果文案：

- `鱼鱼码有效，可以添加`
- `这是你自己的鱼鱼码`
- `这个好友已经添加过`
- `鱼鱼码有效，但使用了不同的中转站`
- `鱼鱼码格式无效`

#### 消息显示

`消息停留时间`使用 segmented picker：

- `10 秒`
- `20 秒`（默认）
- `30 秒`
- `直到点击`

说明：`每条消息独立计时；新消息会顶开旧消息，不会覆盖。`

其余设置：

- `收到消息时播放提示音`
- 声音选择与`试听`
- `允许好友串门`
- `显示好友选择的气泡颜色`

身份无效时禁用发送、串门和复制鱼鱼码，但保留聊天历史读取。

### 1.5 设置窗可访问性

- 状态使用图标加文字，不能只靠颜色。
- 正文对比度至少 `4.5:1`，点击区域至少 `28 × 28 pt`。
- 输入框必须有持久标签；错误信息与对应字段关联。
- 异步检测完成后向 VoiceOver 宣告结果。
- 键盘焦点按视觉顺序移动；侧栏支持上下方向键。
- `⌘,`打开设置，`⌘W`关闭。
- 放大字体时卡片增高，按钮文字不得截断。
- Reduce Motion 开启时取消弹跳和旋转，只保留短淡入。

## 2. 鱼鱼聊天窗目标规格

### 2.1 窗口骨架

| 项目 | 规格 |
| --- | --- |
| 默认内容尺寸 | `680 × 520 pt` |
| 最小内容尺寸 | `600 × 440 pt` |
| 好友栏 | 固定 `190 pt` |
| 分隔线 | `1 pt` |
| 对话区 | 自适应，默认约 `489 pt` |

### 2.2 好友栏

- 标题`鱼鱼聊天`，顶部区高 `48 pt`。
- 搜索框高 `30 pt`，区域内边距 `12 pt`。
- 好友行高 `56 pt`；角色标识 `30 × 30 pt`。
- 名称 13 pt Semibold，消息预览 11 pt 单行截断，未读角标最小 `18 × 18 pt`。
- 排序为：有未读、最近有消息、其他好友。
- 串门状态必须显示`串门中`，不能只显示彩色圆点。
- 空状态文案为`还没有鱼友。`，按钮为`前往设置添加好友`。

### 2.3 对话头部

高度 `54 pt`，水平内边距 `16 pt`。

左侧显示好友名称与状态；状态可为`最近收到消息`、`串门中`或`已静音`，不得伪造在线状态。

右侧提供：

- `邀请串门`／`结束串门`
- 更多菜单：`静音`、`查看鱼鱼码信息`、`移除好友…`、`封锁好友…`

### 2.4 消息时间线

- 外边距 `16 pt`。
- 同一发送者连续消息间距 `6 pt`，不同发送者间距 `12 pt`，日期分隔上下间距 `18 pt`。
- 气泡最大宽度为对话区的 `72%`，且不超过 `310 pt`。
- 气泡内边距为水平 `10 pt`、垂直 `8 pt`，圆角 `11 pt`。
- 好友消息靠左，自己的消息靠右；发送者不能只靠颜色区分。
- 好友自定义颜色只用于浅色背景或色条；文本颜色必须自动满足对比度。
- 自己的消息状态只使用`发送中`、`已发送`和`发送失败 · 重试`；未实现回执前不得显示`已读`。
- 发送失败时保留原文和重试入口。

滚动规则：

- 用户位于底部时自动跟随新消息。
- 用户查看旧消息时不强制跳到底部，改显示`N 条新消息`按钮。
- 只有窗口激活且对应会话可见时才标记已读。

### 2.5 输入区

- 默认高 `88 pt`，内容增长时最高 `116 pt`。
- 外边距 `12 pt`；输入框最小高 `38 pt`、最大高 `78 pt`。
- 右下显示 UTF-8 计数，例如 `320 / 1000 字节`。
- 主按钮为`发送`；失败消息使用独立的`重试`。
- `Return`换行，`⌘Return`发送，`Escape`取消回复状态，`⌘K`聚焦好友搜索。
- 输入为空、身份无效或好友被封锁时禁用发送，并提供可访问的禁用原因。

### 2.6 聊天窗可访问性

- 每条消息的 VoiceOver 标签包含发送者、正文、时间与状态。
- Accessibility 阅读顺序始终按时间顺序，不受左右布局影响。
- 未读标签使用完整描述，例如`Kinley，3 条未读消息`。
- 串门、静音与失败状态必须有文字。
- `重试`与具体失败消息关联。
- 窗口获得焦点时不强制抢焦点到输入框。
- Reduce Motion 开启时把上推弹簧动画改为短淡入。

## 3. 角色系统台词

共同规则：

- 好友消息正文必须原样显示，角色台词不能改写或代替正文。
- 技术原因由 UI 解释；角色只提供简短情绪反馈。
- 失败时不责怪用户，并说明内容仍被保留。
- 身份无效属于安全阻断，不得暗示绕过。

### 3.1 水滴鱼

语气：疲惫、略委屈、嘴硬但会处理；常用`……`、`我先`、`还在`。

| 事件 | 规则 | 样例 |
| --- | --- | --- |
| 来访 | 勉强让位但实际欢迎，不高声兴奋 | `……来了就待会儿。` `别挤。我会让一点。` `牵好了。慢慢游。` |
| 收到消息 | 只提醒有话送到，不加工正文 | `朋友的鱼找你。` `……这句是给你的。` `有话送到了。我先拿着。` |
| 发送失败 | 明确话还在，可以重试 | `这句没送到。话还在。` `路上断了……再试一次吧。` `我没递过去。先别重写。` |
| 身份无效 | 平静阻止发送并指向设置 | `鱼鱼身份不对。我先不传。` `钥匙没对上……去设置看看。` `这条传话线不能用了。先修一下。` |

### 3.2 小草团

语气：木讷、慢半拍、植物冷幽默；使用风、根、叶与生长意象。

| 事件 | 规则 | 样例 |
| --- | --- | --- |
| 来访 | 安静接待，以植物空间表达欢迎 | `客人到了。我挪一片叶子。` `风把你带来了。站这边吧。` `一起走。别踩根。` |
| 收到消息 | 短促平静，使用落下或长出意象 | `有消息落下来了。` `朋友的鱼说话了。` `新叶子……不，是新消息。` |
| 发送失败 | 用风或生长表达失败，同时允许重试 | `风没接住。内容还在。` `这句话没送出去。` `路没长通。可以再送一次。` |
| 身份无效 | 用根和生长隐喻身份问题，不卖萌 | `身份没长好。先去修一下。` `根上的钥匙不对。` `这条传话线断了。设置里能修。` |

## 4. 仍需人工视觉 QA

以下项目只有在用户批准并由人工查看应用后才能确认：

- `820 × 600 pt` 下五项侧栏、卡片密度与底栏是否拥挤。
- 长中英文文案、放大字体和最小窗口尺寸下是否截断。
- 鱼鱼码三行区域、验证状态与安全警告的视觉层级。
- `680 × 520 pt` 下好友栏、气泡最大宽度和输入区的实际平衡。
- 深色模式、系统高对比模式与自定义气泡颜色的可读性。
- VoiceOver 焦点、键盘路径与异步状态宣告。
- Reduce Motion 下各状态切换是否仍清楚。
- 多条消息、长消息、空历史、发送失败和身份无效等极端状态。
- 四款鬧鐘在实际角色手持尺寸、响铃震动与两种角色配色下的辨识度。
- 四款消息提示在 42 pt、`1` 与 `9+` 数字覆盖时的位置、对比度和命中范围。

人工视觉 QA 完成前，不得把本文中的目标尺寸或视觉适配描述为已验证结果。

## 5. 原创建模图标系统

- 鬧鐘使用圆润玩具感、分层体积与柔和高光等一般视觉语言，不描摹 Apple emoji 路径。默认「珊瑚抱抱钟」，备选为海沫、蜂蜜方钟与梅子夜钟。
- 未读提示避开传统红色圆点/胶囊，提供举旗小邮箱、软角信封、飞来信与漂流瓶信；数量必须进入物件本身的邮旗、封印、信封或信纸区域。
- 所有图标使用 `0 0 100 100` SVG、粗圆轮廓与少量层次，目标显示尺寸为 36–42 pt；运行资源与概念源稿均保留 CC0 来源声明。
