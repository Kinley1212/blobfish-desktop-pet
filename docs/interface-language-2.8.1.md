# 界面语言维护记录 · 2.8.1

## 约定

- 原生设置语言代码：`zh-CN`、`zh-HK`、`en`。未知代码沿用简体中文回退，不将香港繁体改写为简体。
- 界面切换入口保留在设置的“台词”页，不增加重复入口。当前窗口预览，应用后持久化、更新菜单。
- `InterfaceText` 区分产品文案字面量和插入值，只转换字面量。`InterfaceLanguage.authored` 仅用于产品自有名称，不得传入消息、任务正文、用户标签或路径。
- 香港繁体使用系统字符转换加明确的香港界面用词映射，转换缓存最多 1024 条；无联网翻译或模型调用。
- 设置状态保存原始双语模板，切换语言时重渲染当前四个状态字段；系统错误后缀保持原文。不要通过重新载入配置来刷新语言，那会覆盖尚未保存的输入。
- 台词仍由 `SpeechLanguagePolicy` 与角色语言包控制，不能改成依赖界面语言。
