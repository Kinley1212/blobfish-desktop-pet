# 水滴鱼 2.8.0 正式版

macOS 正式发布，支持 Apple Silicon 和 Intel。延续项目的 ad-hoc 签名，不使用 Apple Developer ID 或公证，不包含本地尚未提交的 Windows 改动。

## 相比 beta 的修复

- 关闭问题正文展示后，必要的人工处理提醒不再遗漏。部分连接器通过提问协议请求审批；这类阻塞请求仍会用通用台词提醒，不显示其正文。
- 校验问题的任务、轮次、重复 ID、选项和文字上限，防止损坏缓存造成串题、异常大面板或错误跳转；省略正文不丢弃必要等待状态。
- 多个观察器共用最多 64 个任务、64 KiB 预览正文的预算，避免实例数量放大界面负载。
- 忽略未知结束状态；已结束任务清除遗留审批元数据，避免误报完成或要求处理已结束任务。
- 保留 beta 中的设置异步竞争、重复事件、旧缓存恢复、滚动位置、管道断连及内存积压修复。

## 功能与设置

- 小型粉色 Codex 问题面板，多题翻页、纵向选项、长文滚动，跟随水滴鱼，支持浅色/深色。
- “设置 → 连接与隐私 → 显示 Codex 问题与选项”默认关闭。关闭立即收起面板，观察器约 2 秒内停止收集并清除正文；必要人工处理提醒独立保留。
- 问题与选项只预览，回答仍在 Codex，不代批、不自动选择答案。秘密问题不预览、不落盘。
- 两个角色四份语言包共新增 36 句单题、多题和边做边问反应。

## 验证

- 原生自检 109/109 通过，包含隐藏问题的提醒去重、缓存归属和合并上限回归测试。
- 精确发布源码的干净副本：全部 Node 测试 374/374 通过，未混入 Windows 未提交文件。
- 观察器 3 项测试通过：原字节转发、断连进程清理、100,000 条流式消息与 8,000 条状态事件；108.04 MiB 数据 SHA-256 一致。
- 本机压力样本突发约 3.53 秒，额外峰值 RSS 9152 KiB（约 8.9 MiB），结束后 CPU 0.0%。饱和输入时采样接近一个 CPU 核心；不将短期压测当长期真实负载保证。

## 接入方式与已知边界

需要在设置中定位专用启动器。请在方便时保存工作、自行完全退出 Codex，再用启动器打开；启动器不会强制重启。退出后按普通方式打开 Codex，即可恢复不带观察器的启动方式。

该可选接入按本机桌面附带 CLI 0.153.0-alpha.5 核验。未使用启动器的任务保留旧 hooks 行为，不能保证同等的自动审核/人工审批区分。**真实桌面会话、多题回答闭环、全屏空间和长期占用仍需验收**；本次正式发布不等于这些未执行项目已通过。不会擅自重启当前 Codex 或替换桌面程序。

只有本机私有短时缓存（目录 0700、文件 0600），不上传问题、不读聊天历史、不调用模型、不修改审批策略。问题预览与必要状态提醒相互独立。
