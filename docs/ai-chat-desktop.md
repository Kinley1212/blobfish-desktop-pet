# 桌面 AI 聊天（本地测试版）

## 交互

从“和角色聊天…”进入。台词显示在桌宠原有气泡中；独立选项框与输入框放在鱼下方，没有整块背景面板、重复角色预览或选项序号。靠近屏幕底部时为回复栏上移留空间，聊天中暂停位置游动，但保持轻微浮动、摆动和呼吸，选项框不会随动作晃动；减少动态效果时停用新增聊天动作。更多和关闭使用一组紧凑的灰白工具栏，居中图标、中间分隔线，右侧与选项对齐。省略号改为 AppKit image-only 按钮，避开 SwiftUI Menu 隐藏箭头后仍保留的不对称内边距。Esc 或小叉关闭；鱼恢复活动。

回复区宽 248 pt，选项和输入字体 12 pt；选项最低高 26 pt，输入框高 32 pt。AI 聊天工具栏提供展开/收起选项按钮，收起后保留输入、发送及工具栏；本次聊天的新回复不会自动展开，不清空草稿或重建输入框。本地对话和小游戏没有自由输入，因此始终显示所需选项。窗口随折叠重新计算高度，仍贴在鱼下方。

未启用 AI：原有对话分支与本地小游戏。启用 AI：打开聊天时生成开场，随后按输入生成台词、2–3 个选项和情绪；表情只使用当前角色支持的素材。聊天菜单提供换个话题、小游戏、重新聊天、记住上一句。小游戏输赢仍由本地规则决定。

普通闲聊暂停；任务、传话和紧急提示仍可插入，结束后恢复当前聊天气泡。打开好友传话、隐藏鱼时关闭桌宠聊天并取消请求。迟到回复不能重新打开窗口。

## 设置

“设置 → 台词 → AI 聊天”：填写 Chat Completions 基础地址或完整接口地址（根地址和以 `/v1` 结尾的地址会自动补 `/chat/completions`，其他自定义路径保持原样）、模型名称和 API Key，保存密钥，测试连接，再启用并点“应用”。密钥按完整地址隔离存入系统钥匙串，修改地址不会把旧服务的密钥发送给新服务。

协议使用 POST JSON、Bearer 认证、`model`、`messages`、`stream: false` 和 `max_tokens: 600`，读取 `choices[0].message.content`。这是 Chat Completions 兼容接口适配器，不是任意厂商协议自动适配；仅支持其他输出参数（如仅接受 `max_completion_tokens`）或 Responses/Messages 协议的模型需另加适配。DeepSeek 官方地址额外使用 `thinking: {type: "disabled"}` 与 `response_format: {type: "json_object"}`，避免默认思考模式耗尽短回复预算；其他服务不附加这些参数。参见 [DeepSeek 接口文档](https://api-docs.deepseek.com/api/create-chat-completion/)。

接口参考：[Chat Completions 官方文档](https://developers.openai.com/api/reference/resources/chat)。

远程地址必须 HTTPS；HTTP 只允许本机 loopback。禁止 URL 中的用户名、密码、查询参数和 fragment；不跟随重定向转发凭证。请求使用无磁盘缓存和 Cookie 存储的临时 URLSession。请求/资源超时 25/35 秒，响应读取上限 64 KB。格式修正最多重试一次；网络或鉴权失败不自动反复请求。连接测试不带聊天内容，但可能产生服务用量。

中文输入法沿用原生传话编辑器：Return 确认组字或发送，Command-Return 换行。输入上限 4 KB；等待回复时继续编辑的新草稿保留。

## 台词与表情

每次请求读取当前角色、台词语言包的 style.json 与少量内置对话示例。模型只返回 text/options/emotion；程序校验长度、选项数量和去重、情绪白名单，并挡住明显客服式输出。英文台词最多 360 字符、中文最多 120 字符，选项分别最多 60/24 字符。模型不能执行桌面操作或修改设置。

水滴鱼与小草团分别映射到各自表情。文字、表情在同一轮更新；关闭恢复状态表情。语气仍受所选模型能力影响，不能仅凭结构校验保证所有回答完全一致。尚需使用用户选择的真实服务做语气验收。

## 陪伴式对话

AI 设置提供“陪伴时的闲聊兴趣”，最多 1 KB，可编辑。默认偏向日常小事与心情、个人喜好与小期待、共同想象的宠物日常，偶尔聊自然或生活趣事。读取旧配置时仅替换上一版原样的默认兴趣，自定义兴趣保留。兴趣不限制用户主动聊的内容。

没有预写题库或固定新闻源。去掉每五轮触发换题的计数器：开场、正常接话、用户主动换话题使用不同的对话意图，模型按上下文决定具体内容。开场是自然地见面，正常接话优先延续当前情绪和话题，主动换题才明确离开上一主题；开场和换题指令不写成用户记忆。

提示词要求开心时一起高兴，烦闷时先回应具体经历，需要帮助时再给建议；允许短回应、安静陪伴和自然结束。不每轮追问，也不固定提供玩笑或反对选项。鱼保留原有别扭、轻微抱怨、暗自关心的语气，并有自己的小偏好和反应；不假装看到桌面或经历了真实事件。

只从已有对话和记忆中适度提起一件相关小事，不编造回忆、不擅自断定用户心情、不把旧事说成今天或昨天。不用内疚、占有欲或离不开用户的说法挽留。陪伴策略不增加后台请求；本地记忆容量单独限制如下。

当前未接入实时搜索：提示词明确禁止假装联网或将训练知识当作近期新闻。用户已选择暂缓联网检索，没有启用固定 RSS、新闻后台轮询或额外收费调用。

试聊验收应覆盖：分享小好消息、吐槽具体遭遇、说不想聊、仅回复一个字、要求换题、提起已经存下的喜好、离开后再打开聊天。关注是否接住具体内容、是否自然延续、不连续盘问，以及退出是否无挽留。自动自检验证配置迁移、请求意图、记忆隔离和上下文预算，不能替代真实模型的语气验收。

## 时间上下文

每次请求提供设备当前的本地日期、时分秒、UTC 偏移及 IANA 时区。每条历史消息也附原始发送时间；用户发送和鱼回复分别记录，跨午夜、时区变化和夏令时按各自的原始时区解释。网络失败后的“再试一次”沿用最初发送时间，不把重试当成一句新说的话。

长期记忆区分保存时间与原话时间：从聊天保存时保留那句原话的时间，设置中手动添加按提交时刻记录。时间字段也计入记忆的条数和字节上限。旧版没有时间的消息和记忆仍可读取，显示给模型的时间为 unknown，不用文件修改时间、载入时间或排序猜测日期。

提示词要求用时间理解先后、隔了多久和“今天/明天”等相对日期，但不强制报时、按时段问候或围绕时间找话题。记录时间不等于事情发生时间，也不能仅凭时间过去就断定某事发生或心情改变。时间只放入提供给模型的上下文，不作为新字段发送给不支持它的 Chat Completions API，不显示为聊天正文。

## 本地记忆及隐私

仅保存和 AI 桌宠的聊天，文件为应用数据目录内 `ai-chat-memory.json`（0600）；API Key 不在其中。不读取桌面文件、好友传话、任务正文或其他应用内容。

- 最近最多 150 组问答（300 条消息），编码后不超过 1 MB。
- 最多 100 条明确保存的长期记忆，编码后不超过 96 KB；单条最多 512 UTF-8 字节。
- 整个存储文件限 1.5 MB，固定私有临时文件用于原子更新；持久文件加一次完整临时写入不超过 3 MB，无不断增长的日志和备份。扩大本地容量不会增加每轮发送的上下文预算。
- 每次最多带最近 6 轮问答和 4 KB 保存记忆，优先选最近保存的完整条目；消息正文预算 24 KB，JSON 包装另有少量开销。未使用向量数据库或后台摘要模型。
- 用户说“记住/remember…”或通过聊天菜单、设置明确保存长期记忆。没有自动推断长期个人事实；仅在成功回复后保存问答。
- 设置可查看、增加、逐条删除或清空。删除单条同时清空近期上下文，防止旧问答带回已删事实；删除操作取消进行中的聊天请求并清空会话上下文。
- 关闭记忆后不发送或更新旧记忆，只保留当前窗口的有限上下文。已有文件留在本机，用户可另行清空。

记忆在本地存储；被选入上下文的内容仍会发送给配置的 API 服务，不代表完全离线推理。程序不记录密钥、请求正文或服务错误正文。

## 验证与交付边界

自检覆盖配置迁移、地址与输出校验、字节与条数上限、私有文件/符号链接拒绝、删除记忆、禁用记忆、格式修正、失败回退、取消与迟到回包、新草稿保留、台词语言独立、HTTP 响应上限/错误/重定向拒绝，以及透明窗口与屏幕边缘布局。

网络检查使用进程内 URLProtocol 模拟响应，没有调用真实收费 API。窗口布局检查使用不显示的 hosting view，没有截图或桌面视觉验收。用户提供 API 配置后的真实响应、语气和多屏/输入法实际操作仍需试用确认。

本文对应原生 AI 聊天实现，正式安装包的发布状态以 GitHub Releases 为准。桌面测试版通过单独备份、签名与校验后替换；用户数据和钥匙串保留。

## 最近任务背景（2.9.1）

- “让鱼了解最近任务”默认关闭；启用后仍需开启任务标题和相应 Codex / Claude Code 连接。关闭任一条件即停止该范围任务背景的读取或发送。
- 聊天请求时在后台读取已有私有 Hook 状态文件：最近 3 天、最多 6 条，每条只提供标题、最后记录状态和 UTC 事件时间；不包含 session ID、目录字段、任务全文、代码或工具输出。
- 背景是 user 角色中的 JSON 数据，不能变成系统指令。模型不能把记录时间当截止时间，不能将过期 running 或 ended 推断为仍在执行或成功完成；仅在适合聊工作时自然提到，不反复催进度。
- 最多 3 KB，包含于原有 24 KB 消息正文预算。不新增本地历史文件，不占用额外聊天记忆空间；与“保存本地聊天记忆”独立，关闭后后续请求不再附加任务背景。已发给提供方的内容无法由本地开关撤回。
- 聊天回复区的实际矩形传入场景布局，聊天气泡优先于任务标题放置；任务标题、提示气泡和其他卫星面板避开输入及选项区。纯几何自检覆盖展开、收起与屏幕边缘，不代替用户真实桌面验收。

## 表情恢复与结束聊天

回复表情保持 5 秒后恢复，保留当前台词和原始消息时间；新回复重置计时。用户点击叉号或按 Esc 时立即关闭回复栏，启用 AI 时用当前会话生成一句告别（最多一次请求，不写入聊天记忆），5 秒未完成则取消并显示本地告别。告别说话与表情持续 5 秒。再次打开聊天取消旧告别；隐藏鱼、切换好友聊天等程序关闭不额外发起告别请求。
