# 水滴鱼 2.7.0 · macOS 随身小邮局

## 新界面与传话体验

- 传话页改为粉色信封和信纸，配套浅／深色外观。
- 三个快捷互动改为右侧竖排，贝壳小门提供“去串门／回自己家／处理中”状态。
- Enter 换行、Command + Return 寄出；保留 1,000 UTF-8 字节限制与输入法组合文字保护。
- 传话与历史窗口改为支持全屏空间的非激活辅助面板，不再强制激活整个应用；传话面板继续依附水滴鱼并限制在当前屏幕工作区。
- 已读范围限定当前联系人；独立历史窗口不再暂停角色或提供快捷回复。

## 稳定性与常驻开销

- 快捷闹钟适配深色模式；快捷设置与设置草稿同步，避免覆盖刚修改的游动开关。
- 更新安装和系统提醒子进程增加超时保护；任务监控去重，性能采样按实际启用功能调整。
- 发送／接收密文上限一致，身份和历史数据写入前检查容量，防止成功保存后下次启动无法读取。
- 保留主线已有的访客离线通知修复。

## 下载与安装

- Apple Silicon：`BlobfishNative-2.7.0-macOS-arm64.zip`
- Intel Mac：`BlobfishNative-2.7.0-macOS-x64.zip`
- 自动更新清单：`blobfish-native-latest.json`（含两种架构的大小和 SHA-256）

本项目为自用桌宠，正式版使用 **ad-hoc 签名**，不购买 Apple Developer ID，也不做 Apple 公证。首次打开若被系统拦截，请由用户在“系统设置 → 隐私与安全性”确认；不需要也不应关闭 Gatekeeper。

本次仅发布 macOS 原生安装包，不包含尚待 Windows 实机验收的本地开发版本。原生编译与自动化回归已执行；全屏空间切换、中文输入法候选及视觉布局尚未进行人工 GUI 验收，不将自动化通过等同于这些项目已验证。
