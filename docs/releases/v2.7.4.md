# 水滴鱼 2.7.4 · 粉色来信与更新退出修复

- 修复串门状态下退出可能一直等待的问题，退出前收尾加入独立超时。
- 更新重启等待旧进程退出后再启动新版，防止重复点击安装。
- 菜单栏改为**透明背景的粉色水滴鱼**，替换鱼 emoji。
- 迷你传话框直接显示互动和串门小图标，保持 240×132 pt 默认内容区。
- 聊天记录采用粉色便笺风格：柔和好友栏、暖纸消息气泡、紧凑抬头和底部信纸输入区，适配深色模式。
- 聊天记录可直接发送，草稿按好友保存；回车发送，Command＋回车换行。

原生自检与消息／设置代码检查通过；未进行真实好友消息、全屏或视觉验收。2.7.3 的发布构建因追加聊天记录设计主动取消，本版包含其全部修复。
