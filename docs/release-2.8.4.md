# 水滴鱼 2.8.4

- 右键新增「隐藏水滴鱼」，可选 1、5、15、30 分钟；到时自动返回，也可从菜单栏点「立即回来」。
- 水滴鱼保持大小和高度，横向游到珊瑚后，再与珊瑚一起淡出；返回时先一起显现，再横向游出来。
- 珊瑚优先出现在屏幕内有空间的一侧；支持系统「减少动态效果」。
- 隐藏期间暂停画面动画，普通消息不会重新唤出角色；计时及消息服务继续运行。睡眠后按实际到期时间返回。
- 四套内置语言包各有 11 句隐藏台词和 11 句返回台词，沿用随机选句及近期避重复机制。

提供 Apple Silicon 和 Intel 原生 macOS 安装包及自动更新清单，沿用 ad-hoc 签名。
