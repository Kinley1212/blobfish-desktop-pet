# 水滴鱼 2.8.1

## 界面语言

- “设置 → 台词 → 界面语言”支持简体中文、繁體中文（香港）、English。
- 设置文字即时预览；点击“应用”保存语言并更新右键菜单，重新打开仍保留选择。
- 香港繁体使用“設定、介面、滑鼠、記憶體”等界面词汇；设置中的角色、配件及状态名称同步显示。
- 已显示的应用状态提示随语言更新。昵称、好友输入、系统错误原文和闹钟自定义名称不参与繁简转换。
- 界面语言与角色台词语言独立，切换不重置未保存的其他设置。
