# 水滴鱼 2.8.2 正式版

## 串门响应

- 点击串门先显示右上角电话图标，等待对方接受后才显示鱼鱼，不再把中转投递成功当成接通。
- 接通后播放约 1.25 秒的粉色小门打开、鱼鱼出场、门消失动画；支持系统“减少动态效果”。动画不改变角色碰撞范围或甩动速度。
- 支持等待期间取消呼叫；网络失败、40 秒无响应、关闭串门或屏蔽/静音好友会清理等待状态。
- 新版回应关联邀请 ID；迟到或不匹配的接受回复不会触发出场。修复状态回滚和已结束串门的迟到发送回调处理。

## 输入框修复

- 中文输入法组字时隐藏“说点什么…”占位文字，清空输入后恢复。
- 传话框和聊天记录回复框共用修复；保持回车确认候选、回车发送和 Command-Return 换行的既有规则。

## 验证与边界

- 原生自检 114/114、原生专项 Node 检查 18/18 通过，包括 1,000 组握手匹配样例、动画阶段及碰撞范围不变检查。
- 精确待发布源码的隔离副本：完整 Node 测试 379/379 通过，包含观察器传输及压力测试。
- 未进行真实双机/中转联调或视觉截图验收，自动化测试不等于这些场景已验收。
- 旧版对方未回传邀请 ID 时使用好友与时间回退验证，依赖双方时钟大致同步；新版之间使用请求 ID 关联。排队超过 40 秒的旧邀请不再触发串门。
- macOS 原生版本，提供 Apple Silicon 与 Intel 安装包及稳定更新清单；不包含尚未提交的 Windows 改动。
- 沿用 ad-hoc 签名，不使用 Apple Developer ID 或公证。首次打开可能需要在系统“隐私与安全性”中确认。
