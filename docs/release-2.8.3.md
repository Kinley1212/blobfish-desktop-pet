# 水滴鱼 2.8.3

## 运行开销优化

- 多个显示刷新订阅共用一个底层时钟。角色反应、完成提示、闹钟震动和闹钟进出动画改用共享回调，保留原有时长和更新频率上限。
- 合并同一帧内的角色图层变换及重复位图重建；倒计时文字变化只刷新浮层。
- 任务租约和 Codex 观察快照复用未变化文件的解析结果。每秒过期判断、当前权限检查和问题内容校验保持不变，取消或结束的提醒不会因缓存继续显示。
- 缓存设有数量及源文件体积预算，并随文件移除、过期或停止监控清理。缓存以少量有界常驻对象减少重复读取和临时分配；尚无整应用 CPU/RSS 对比，不承诺具体降幅。

## 串门体验

- 等待接通时，电话图标短促震动后停顿；取消、接通或超时后停止。
- 入场约 2.4 秒：访客从侧上方的小门由小变大、斜向靠近，伴随轻微上下浮动，到位后门才淡出。
- 串门按钮改为独立圆角门牌，显示“串门 / 取消 / 回家”，与三个快捷互动按钮区分。
- 保留系统“减少动态效果”、原有窗口尺寸、角色碰撞范围、拖动及甩动规则。

## 验证与安装

- 原生自检 121/121、原生专项 Node 检查 20/20 通过；涵盖缓存命中与失效、权限撤销、任务/审批过期、订阅取消及不同刷新率下的动画时间轴。
- 精确待发布源码的隔离副本：完整 Node 测试 381/381、原生自检 121/121 通过，包含 Codex 观察器传输和压力测试。
- 合成缓存检查中，同一未变化文件连续读取 500 次只解析一次；这不是整应用性能基准。
- 未进行真实双机串门、视觉截图或长期 CPU/RSS 验收。
- 提供 Apple Silicon 与 Intel 的原生 macOS 安装包，以及 `blobfish-native-latest.json` 更新清单；不包含 Windows 本地工作。
- 沿用 ad-hoc 签名，不使用 Apple Developer ID 或 Apple 公证。首次打开可能需要在系统“隐私与安全性”中确认。
