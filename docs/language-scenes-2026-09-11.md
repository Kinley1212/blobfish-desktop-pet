# 场景台词与日历彩蛋交接

本轮是源代码推送，不修改版本号、不发安装包。保留未提交的 Windows 构建工作。

## 台词资源

- 四个语言包各新增 160 句，总计 640 句：100 句普通场景、36 句时间彩蛋、24 句日期彩蛋。
- 普通场景覆盖 46 个现有事件；采用 weight=2 和场景冷却，不提高原来的闲聊频率。
- 中英普通场景的触发条件/冷却逐条对应；水滴鱼繁体，小草团简体，英文各自有角色语气。
- 保留原版台词及 3%/2% 电量保护；计时开始不误称全程拿钟，消息发出不误称对方已读。
- 新文件统一使用小写 phrase ID；event 名保留现有大小写规范。不能仅检查 JSON，须通过真正的 language-pack-loader。

## 时间与日期

- 共享规则：`src/packs/calendar-easter-eggs.json`，原生和 Electron 共用。
- 12 个时间：00:00、01:23、05:20、08:08、09:09、11:11、12:34、13:14、17:20、20:20、22:22、23:59。
- 05:20 / 13:14 / 17:20 无概率门槛，但仍遵守不打扰规则。其余时间每个时刻当天仅尝试一次 25% 概率，每天最多播两次，至少间隔一小时。
- 日期主题：元旦、情人节、愚人节、六一、平安夜、圣诞、年末、闰日、每月第一天、春节、元宵、中秋。
- 使用本机时区；春节、元宵、中秋由系统农历计算，不硬编码某年的公历日期，排除闰月。重叠日期优先农历节日，其次公历节日，最后每月第一天。当天最多一条日期彩蛋。
- 生日/纪念日尚未设置，需用户提供具体日期；不能虚构。

## 不打扰与状态

- 跟随 `rareEnabled` 与安静时段，不唤醒屏幕；锁屏、任务、拖动/甩动、已有台词、响铃或角色聊天期间跳过。
- 时间彩蛋只匹配当前分钟，不回补；日期彩蛋等待当天合适的空闲时刻，次日不补播。
- 保存 `calendar-easter-eggs-state.json` 防重启重复，内容仅日期/已尝试事件/配额，不记录用户消息。损坏或无法保存时停用可选彩蛋并记录诊断，不反复弹错误。
- 原生首次轮询不发彩蛋，等待任务监控首次快照；本轮已安排作息/闲聊时也不发，防异步排队导致彩蛋刚出现就被覆盖。
- 支持 macOS 13：用完整农历 dateComponents 获取闰月标志，不直接请求 macOS 14 才支持的 Calendar.Component.isLeapMonth。
