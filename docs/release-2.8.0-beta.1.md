# 水滴鱼 2.8.0-beta.1

本次为 **macOS 预发行版**。Codex 接入涉及桌面附带 CLI 的启动方式，尚待真实会话长期验收，因此不取代 2.7.5 稳定版。

## 新增

- 可选的轻量 Codex 本地事件观察器：区分实际人工审批与自动审核；异步问题不让鱼进入等待状态。
- 粉色紧凑问题面板：多题翻页、纵向选项、长文滚动，跟随水滴鱼，浅色/深色适配。
- 在“设置 → 连接与隐私”独立开启/关闭问题展示，默认关闭。问题与选项仅预览，点击“回 Codex 回答”返回原任务，不代替你审批或回答。
- 两个角色四份语言包新增 36 句 Codex 单题、多题和边做边问反应。

## Debug 与压力测试

- 修复关闭开关后旧异步回调可能重新显示状态、重复结束事件重新触发完成状态、题数超限丢失阻塞提醒、过多遗留快照导致接入失效、翻题保留旧滚动位置、输出断连产生崩溃报告等边界问题。
- 原生自检 107 项通过。转发层 3 项测试包括断连子进程清理、100,000 条流式消息和 8,000 条状态事件；108.04 MiB 数据 SHA-256 逐字节一致。
- 从精确发布源码的干净副本运行全部 Node 测试：374/374 通过，不依赖尚未提交的其他功能文件。
- 本机压力样本：约 7.1 秒完成突发，额外峰值内存约 8 MB，结束后约 4.3 MB、CPU 0.0%。持续饱和输入时短时接近一个 CPU 核心；这不是普通使用时的负载，也不是长期占用保证。
- 批量扫描与逐批释放临时对象，修复压测中发现的内存峰值超标；没有放宽测试上限。

## 使用方式与限制

1. 退出旧水滴鱼，打开本版；在“连接与隐私”启用 Codex 和问题展示并应用。
2. 点击“显示 Codex 专用启动器”。方便时保存工作、自行退出 Codex，再双击启动器打开。启动器不会强制退出或重启当前任务。
3. 恢复普通启动方式：先退出 Codex，再像平时一样打开即可。问题展示开关不影响人工审批提醒。

当前桌面接入核验基于附带 CLI 0.153.0-alpha.5；其他版本需验证。未经专用启动器接入的任务仍使用旧 hooks，不能宣称已具备同等的准确审批区分。真实会话中自动审核、人工审批、多题回答、全屏空间及长期资源使用仍待验收。

只在本机保存短时私有快照（0700 目录、0600 文件），不上传问题，不读取聊天历史，不调用模型，不修改信任或审批规则。秘密问题不预览；关闭并应用立即收起面板，观察器约 2 秒内停止收集并清除问题正文。

## 下载

- arm64 ZIP：Apple Silicon Mac。
- x64 ZIP：Intel Mac。
- blobfish-native-latest.json：本预发行安装包的版本、大小、SHA-256 校验与下载地址；稳定版不会自动升级至本 beta。

两个安装包均为 Swift / AppKit 原生应用，不包含 Electron。本项目坚持自用的 **ad-hoc 签名**，不使用 Apple Developer ID、未经公证。首次打开可在 macOS“隐私与安全性”中确认。本次不包含 Windows 改动。
